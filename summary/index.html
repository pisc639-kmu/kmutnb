Summary

    • Capacitor stores energy in the electric field.
    • Formula
      $$\epsilon = \epsilon_0\epsilon_r$$ $$C = \epsilon \frac{A}{d}$$ $$C = \epsilon_0\epsilon_r \frac{A}{d}$$
    • Parameters
      C = Capacitance (F)
      ε = Permittivity (F/m)
      εᵣ = Relative Permittivity (unitless)
      ε₀ = Vacuum Permittivity (F/m)
      A = Plate Area (m²)
      d = Distance (m)
    • Energy Stored
      $$E = \frac12 C V^2$$
    • Inductor stores energy in the magnetic field.
    • Basic Formula
      $$v = L \frac{di}{dt}$$
    • Inductance Parameters
      L = Inductance (Henries, H)
      N = Number of turns (unitless)
      μ = Permeability (H/m)
      A = Cross-section area (m²)
      l = Coil length (m)
    • Ideal Solenoid
      $$L = \frac{\mu N^2 A}{l}$$
    • Energy Stored
      $$E = \frac12 L I^2$$
  • Time Constant
    $$\tau = RC$$
  • Charging
    $$V_C(t) = V_s\left(1 - e^{-t/RC}\right)$$ $$I(t) = \frac{V_s}{R} e^{-t/RC}$$
  • Discharging
    $$V_C(t) = V_0 e^{-t/RC}$$ $$I(t) = -\frac{V_0}{R} e^{-t/RC}$$
  • Time Constant
    $$\tau = \frac{L}{R}$$
  • Rising Current (Switch ON)
    $$I(t) = \frac{V_s}{R}\left(1 - e^{-tR/L}\right)$$ $$V_L(t) = V_s e^{-tR/L}$$
  • Falling Current (Switch OFF)
    $$I(t) = I_0 e^{-tR/L}$$ $$V_L(t) = -I_0 R e^{-tR/L}$$

    • Resistors

    $$R_s = R_1 + R_2 + \ldots$$ $$\frac{1}{R_p} = \frac{1}{R_1} + \frac{1}{R_2} + \ldots$$

    Capacitors

    $$C_s = \frac{1}{\frac{1}{C_1} + \frac{1}{C_2} + \ldots}$$ $$C_p = C_1 + C_2 + \ldots$$

    Inductors

    $$L_s = L_1 + L_2 + \ldots$$ $$\frac{1}{L_p} = \frac{1}{L_1} + \frac{1}{L_2} + \ldots$$

    Key Trick

    - Capacitor acts like Resistor formula but reversed (series ↔ parallel).
    - Inductor acts like resistor (same formulas as R).
